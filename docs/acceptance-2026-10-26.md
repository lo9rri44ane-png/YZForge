## 清空示例后的开发试跑

从独立检出通过工作台删除 `showcase`、`workshop`、`lobby`、`profile`、`common`，保留删除恢复记录；将不用的示例配置源移出有效目录。再通过工作台创建：

1. `catalog` 模块和 `products` XLSX 配置表，填入 120 条产品。
2. `CatalogService`，加载类型化配置并提供查询接口。
3. `CatalogPage` 与 ViewModel，显示虚拟列表。
4. `ProductRowPart`，通过作用域内点击打开详情。
5. `ProductPopup`，根据类型化参数读取产品数据并返回。

页面、Part、弹窗及绑定由 Creator 序列化并读回 UUID。运行中确认列表仅用 10 个实例显示 120 条数据；第一条和复用后的最后一条分别打开产品 1、120；详情遮罩拦截底层输入；横竖屏变化后仍可操作。App 关闭后作用域、模块、界面、资源和配置持有清空。副本完整 `npm run verify` 的 364 项框架/工具测试通过。

试跑暴露并修复了三个工具问题：新检出只保留空目录的 `.meta`，需通过 AssetDB 补回目录并确认 UUID；按需模块入口预制体名称应与最终文件名一致，避免 Creator 规范化后读回失败；MCP 项目识别不应依赖已经打开编辑场景。自动生成另补了资源库就绪监听，确保首次导入后重试且卸载时释放监听。

## 虚拟列表与生命周期

- 保留固定尺寸纵向列表/网格，增加固定尺寸横向单行和纵向单列变高列表。
- `itemHeight(data, index)` 是同步纯函数；数据或布局更新时计算几何快照，滚动通过二分查找窗口。当前不支持渲染后的异步测量、横向变宽、横向网格或变高多列。
- 校验失败保留原数据和布局；同业务 ID 更新保留实例；方向切换回起点，同方向更新保留并夹紧偏移。
- 单元测试覆盖几何边界、二分窗口与逐项判定的一致性、无效更新原子性及复用清理。实际预览和 Release 检查横向鼠标拖动、定位、变高更新、屏幕尺寸变化、清空重填及关闭。
- 修复页面返回准备与 App 关闭同时发生时，把正常取消错误转成清理失败的问题；运行时回归已覆盖。

接口与限制见 [虚拟列表](virtual-list.md)。没有加入旧代码或旧存档兼容层。
